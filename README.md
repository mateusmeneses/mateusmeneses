## 👋 Sobre mim

Desenvolvedor de software para gestão empresarial: ERP, PDV e integrações fiscais. Vim do Delphi/Pascal e hoje trabalho principalmente com **.NET/C#**, além de **Python**, **TypeScript** e **Flutter**.

Gosto de sistemas que resolvem o problema do cliente no dia a dia, aguentam a rotina de uma operação real e continuam fáceis de evoluir.

## 🛠️ O que eu faço

- **PDV e ERP:** frente de caixa, estoque, financeiro e retaguarda para varejo e serviços
- **Motor fiscal:** emissão de documentos fiscais, SPED e rotinas contábeis
- **Integrações:** APIs, importadores e sincronização de dados entre sistemas
- **Modernização de legados:** migração de sistemas Delphi para .NET sem parar a operação
- **Mobile:** desenvolvimento de aplicativos com Flutter
- **Automação:** scripts e fluxos que eliminam trabalho repetitivo
- **Web:** sites, portais e plugins WordPress
- **Suporte técnico:** diagnóstico e correção de problemas em sistemas em produção
